# 墨笺舟 · 微信公众号 Markdown 排版

**墨笺舟**是面向微信公众号文章的 Markdown 图文排版工具。它在浏览器里提供九套主题、实时预览、在线和本地图片、数学公式，以及可粘贴到公众号编辑器的富文本。无需安装软件或注册账号。

## 三分钟开始

1. 下载本项目并解压，双击打开 [index.html](./index.html)。推荐使用较新的 Chrome 或 Edge。
2. 论文分享示例和原论文结构图会自动显示。点击上方主题卡切换风格，再把左侧内容改成自己的文章。
3. 想体验本地图片导入时，点击 **导入文件夹**，选择项目中的 `examples` 文件夹；编辑器会重新载入示例 Markdown 和 `images` 子目录中的图片。
4. 点击 **复制公众号正文**，到微信公众号后台的文章编辑器里粘贴。粘贴后检查图片、公式、表格和手机预览，再发布。

想先看所有主题，可打开 [theme-atlas.html](./theme-atlas.html)。完整的论文分享示例在 [examples/example.md](./examples/example.md)，原论文结构图文件在 [examples/images/transfomer.jpg](./examples/images/transfomer.jpg)。编辑器内已嵌入这张示例图，因此直接打开 `index.html` 就能看到；导入 `examples` 文件夹可演示一般用户使用本地图片的流程。

如果希望别人直接在网页使用：将整个项目上传到 GitHub 仓库，在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录发布。等 GitHub Pages 给出网址后，把它发给使用者即可。编辑器不会自动保存文章，写作时请及时保存自己的 Markdown 文件。

## 用自己的文章和图片

如果只有一篇 Markdown：点击 **导入 Markdown 与图片**，选择 `.md`、`.markdown` 或 `.txt` 文件。若文章里的图片是相对路径，可在同一次选择中选上图片文件；也可以先导入 Markdown，再导入图片。

如果文章和图片放在同一个文件夹，点击 **导入文件夹**。例如：

```text
my-article/
├─ article.md
└─ images/
   └─ photo.jpg
```

在 `article.md` 里写：

```markdown
![图 1｜我的照片](images/photo.jpg)
```

导入文件夹会保留子文件夹路径。浏览器不会把文件上传到任何服务；新导入的图片只在当前页面内存中用于预览和复制。刷新页面后，需重新导入自己的本地图片；内嵌的示例图仍会自动显示。浏览器只会记住上一次选择的主题。

## 插入在线图片

把图片放在可公开访问的 HTTPS 地址，写成单独一段即可生成带图注的图版：

```markdown
![图 2｜流程示意](https://example.com/images/diagram.png)
```

图片写在段落中时会作为行内图片显示。地址必须直接指向图片，不能是需要登录的网页，也不能是网盘的预览页。若图片没有显示，先在浏览器新标签打开地址，确认它能直接显示图片；有些网站会禁止其他网页引用其图片。请只使用您有权发布的图片。

## 微信公众号排版流程

1. 写作或导入 Markdown，切换主题并检查右侧预览。
2. 检查所有图片是否显示。在线图片建议使用稳定、公开的 HTTPS 地址；本地图片建议与 Markdown 一起导入。
3. 点击 **复制公众号正文**，粘贴到微信公众号文章编辑器。该按钮复制带内联样式的 HTML 和纯文本；本地图片会作为数据嵌入 HTML，在线图片保留原地址。
4. 在公众号里逐张检查图片。公众号可能会清理数据图片、远程图片或部分样式。如果导入的本地图片没有保留，可以在左侧已载入图片列表中点击 **复制图片**，回到公众号相应位置粘贴；若浏览器不允许图片剪贴板操作，就使用公众号的图片上传按钮上传原图。示例图可直接从 `examples/images/transfomer.jpg` 上传。
5. 用公众号的手机预览功能检查标题、间距、表格、代码和公式。确认无误后再发布。

**下载 HTML** 可把当前排版保存为一个独立网页，作为备份或进一步编辑。它不是微信公众号的发布文件；公众号文章仍需要在公众号后台粘贴并确认。

> 不同浏览器、公众号后台版本和图片来源的粘贴结果可能不同。工具会尽力保留排版，但无法替代发布前在公众号中的最终检查。

## 常用 Markdown 写法

| 想要的效果 | 写法 |
|---|---|
| 大标题 | `# 标题` |
| 小标题 | `## 标题`、`### 标题`、`#### 标题` |
| 加粗和斜体 | `**重点**`、`*强调*` |
| 链接 | `[链接文字](https://example.com)` |
| 图片 | `![图注](https://example.com/image.png)` 或 `![图注](images/photo.jpg)` |
| 引用 | `> 引用内容` |
| 无序列表 | `- 一项` |
| 有序列表 | `1. 第一项` |
| 任务清单 | `- [ ] 待办`、`- [x] 已完成` |
| 行内代码 | 用一对反引号包住内容 |
| 代码块 | 用三反引号开始和结束，可在开头写语言名 |
| 分隔线 | 单独一行 `---` |
| 行内公式 | `$a^2+b^2=c^2$` |
| 独立公式 | 用两行 `$$` 包住公式 |
| 公式围栏 | 三反引号开头标明 `math`、`tex` 或 `latex`，结尾再写三反引号 |

普通 `text`、`python` 等代码块会保留原始字符，不渲染公式。若想把 TeX 排成公式，请用 `$...$`、`$$...$$` 或 `math` 围栏；示例文章同时展示了公式围栏与普通代码块。

资料卡和提示卡采用以下写法：

```markdown
::: summary
**日期**：2026 年 10 月
**主题**：我的文章
:::

::: note
这是提示内容。
:::
```

还可以使用 `warning` 和 `conclusion`。表格的完整写法请看示例文章。

## 项目文件

```text
index.html             编辑器，直接打开即可使用
theme-atlas.html       九套主题对照页
examples/example.md    论文分享示例，覆盖主要 Markdown 元素
examples/images/transfomer.jpg  原论文结构图；也是上传文件夹的演示图片
themes/               九套主题生成的独立 HTML 片段
scripts/generate.js   将示例图片嵌入编辑器，并生成示例、片段和主题对照页
scripts/verify.js     检查渲染与图片处理
```

普通使用不需要 Node.js。仅在修改渲染器或重新生成样张时，安装 Node.js 18 或更新版本，然后在项目目录运行 `npm run build` 和 `npm test`。项目没有 npm 运行时依赖。

如果替换 `examples/images/transfomer.jpg`，请运行 `npm run build`，以更新 `index.html` 内嵌的默认示例图和九套主题片段。

## 技术与隐私

编辑器的 Markdown 解析和排版在浏览器本地完成，不会上传正文。在线图片由浏览器直接向图片网站请求；公式使用从 jsDelivr 加载的 MathJax，断网时显示原始 TeX 文本。若要完全离线使用公式，需要自行托管 MathJax 并调整 [index.html](./index.html) 中的脚本地址。

解析器支持上表和示例中的常用写法，不保证覆盖全部 CommonMark 扩展。原始 HTML 标签会作为普通文字显示，避免把不受信任的 HTML 直接插入预览。

主题样张采用纯 CSS 色块，没有附带来源不明的配色图片。请在发布您自己的文章时检查文字、图片和链接的版权及可访问性。
